# Visual reference

Drop the reference image Saagii shared on Oct 8 into this folder (GitHub: Add file → Upload files) as `city-reference.webp` or `.png`.

What we took from it (see design-spec.md, Revision 2):

- Mint ground everywhere, fading into the page.
- Near-isometric camera from above, no rotation.
- Light grey streets with white lane dashes; white raised plots for buildings.
- Low-poly teal trees, round and pine.
- Modern white buildings with dark window bands.
- Big low-poly white clouds drifting over the town, casting soft shadows.
