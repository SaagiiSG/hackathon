# Visual reference

Drop the reference image Saagii shared on Oct 8 into this folder (GitHub: Add file → Upload files) as `city-reference.webp` or `.png`.

What we took from it (see design-spec.md, Revision 2):

- Mint ground everywhere, fading into the page.
- Near-isometric camera from above, no rotation.
- Light grey streets with white lane dashes; white raised plots for buildings.
- Low-poly teal trees, round and pine.
- Modern white buildings with dark window bands.
- Big low-poly white clouds drifting over the town, casting soft shadows.

## Revision 3 (Oct 8, evening): `city-vibe.jpg` replaces the look above

A high-key, near-monochrome white architectural model:

- White ground and strong white fog; the town floats in white. No mint ground.
- Pure white buildings with a fine light-grey facade grid of window cells. A few cells per floor lit warm `brand-yellow`, a few pale grey. No colored floor bands.
- Labels are small floating white pills: a dark dot, the name in sentence case, a muted count ("● July 2026  6").
- Everything else desaturated to match: pale roads, pale mint lawns, pale low-poly trees, white lodges with friend-tinted roofs, white/grey cars, soft low-contrast shadows.
- The UI floats over it as liquid glass (see `glass` in `app/globals.css`).
